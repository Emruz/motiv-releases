# Security Policy

## Supported Versions

Only the latest release of Motiv receives security fixes. Please update to the newest version before reporting an issue.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a Vulnerability

Please do not report security issues through public GitHub issues, discussions, or pull requests.

Report vulnerabilities privately by either:

- Using GitHub's **Report a vulnerability** button on the Security tab of this repository, or
- Emailing **security@emruz.com**

Include as much of the following as you can:

- Motiv version and operating system
- Description of the issue and its potential impact
- Steps to reproduce, or a proof of concept
- Any relevant logs or screenshots

## What to Expect

- We will acknowledge your report within 5 business days.
- We will keep you informed as we investigate and work on a fix.
- Once a fix is released, we will credit you in the release notes unless you prefer to remain anonymous.

Please give us a reasonable amount of time to address the issue before disclosing it publicly.

## Scope

In scope:

- The Motiv desktop application
- Licensing and activation through emruz.com

Out of scope:

- Issues in third-party dependencies that are already publicly known
- Social engineering or physical attacks
- Denial of service attacks
