# Motiv

Meeting notes, summaries and answers, on your own machine. Motiv records your meetings, transcribes them locally and writes summaries with the AI model you choose.

## Download

Get the latest version from [Releases](https://github.com/Emruz/motiv-releases/releases/latest):

- **Mac (Apple Silicon):** `Motiv_<version>_aarch64.dmg`. Open it and drag Motiv to Applications.
- **Windows:** `Motiv_<version>_x64-setup.exe` (or the `.msi`).

Each download has a matching `.sha256` file. To check a download, put both in one folder and run `shasum -a 256 -c Motiv_<version>_aarch64.dmg.sha256` (Mac) or `Get-FileHash Motiv_<version>_x64-setup.exe` and compare (Windows).

Builds aren't code-signed yet. On a Mac, the first time, right-click Motiv in Applications and choose **Open**. On Windows, if SmartScreen appears, choose **More info → Run anyway**.

## Updates

**About → Check for Updates** tells you when a new version is here and links to it. Download and install it over the old one; your meetings and settings stay.
